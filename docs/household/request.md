# Ask for a movie or show

Use **Seerr**: `https://seerr.fortwow.dev` (works in any browser — save it to
your home screen).

1. Sign in with **Use your Jellyfin account** — type the same username and
   password you use for Jellyfin.
2. Search for the movie or show.
3. Tap it, then **Request**. For a show, pick which seasons.

That's it. You don't need to do anything else — requests go through
automatically.

## What happens next

A 4K movie or season can take anywhere from about an hour to several hours
to download, then it shows up in Jellyfin within another 15–30 minutes.

| Status in Seerr | Meaning |
|---|---|
| Requested / Processing | It's being fetched. |
| Partially Available | Some episodes are ready; the rest are on the way. |
| Available | Ready — open Jellyfin and it's there. |

If something has said *Processing* for more than a day, tell Brandon.
